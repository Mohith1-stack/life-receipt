# life-receipt

Frontend-only digital experience that turns disconnected digital moments (music, locations, purchases, messages) into a single interactive story.

## Run locally

Open `/home/runner/work/life-receipt/life-receipt/index.html` in a browser, or serve the folder:

```bash
cd /home/runner/work/life-receipt/life-receipt
python -m http.server 8000
```

Then visit `http://localhost:8000`.
